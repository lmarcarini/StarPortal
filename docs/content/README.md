# Content

This folder holds the game's authored content in plain English before it becomes data: puzzle
documents, images described for the artist, solutions, hints, world dossiers and the positions
that make each answer a real address. Each file comes from a design card and is the source the
content and localisation cards build from. Nothing here is final until the project owner
approves it on its pull request; once approved, a change to a file here goes through a new card
and a new approval, and any change to names or lore lands in the bible first.
