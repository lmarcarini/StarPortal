# Playtest guide: M4.6, "Menus and test tools"

M4.6 adds a main menu, a pause menu with named saves, shipped scenarios and a cheat panel. No
game rules change. Plan on 20 minutes. Saves from M4.5 still load.

## Main menu

The game now opens on the main menu. Nothing ticks behind it.

- **New game** starts a fresh base, paused.
- **Continue** appears only when a save exists and opens the newest one.
- **Load** lists every slot, newest first. A save that cannot load is greyed with its reason.
- **Scenarios** lists the shipped starting states (see below).
- **Keys** shows the controls. **Quit** closes the game.

## Pause menu

Esc (gamepad Start) opens it when nothing else wants Esc. It holds the clock; Resume puts the
speed back, and a game that was paused stays paused. Time pause on the gamepad is now L3.

- **Save** lists the slots; type a new name (letters, digits, `_` and `-`) or overwrite one
  after a confirm.
- **Load** asks first if you have played since the last save.
- **Main menu** and **Quit** ask first. Quick save (F8) and quick load (F9) still work.

## Cheats

Cheats are on in debug builds. In a release build start the game with `--cheats`:

```
godot --path . -- --cheats        # from the editor install
FarSideProtocol.exe --cheats      # an exported build
```

F10 shows and hides the cheat panel. It works while paused. The two inputs at the top are the
id (a role, faction or artefact id) and the value. Each use writes a `(cheat)` line to the log.

| Button | Does |
| --- | --- |
| +$1,000k funds | Adds $1,000k. |
| Set Confidence (value) | Sets Confidence to the value, 0 to 100. |
| Fill capacitors | Fills stored energy. |
| Finish research | Finishes the current research project. |
| Finish sites and digs | Completes every building site and dig in progress. |
| Add staff (id = role, value = skill) | Hires one person of that role at that skill. |
| Set standing (id = faction, value) | Sets standing with that faction. |
| Grant artefact (id) | Adds that artefact to the vault. |
| Unlock all research | Marks every project as researched. |
| Heal all | Heals every injured or sick person. |

A bad id or value shows the reason under the buttons and changes nothing.

## Turning a save into a scenario

1. Play to the state you want and save it to a named slot from the pause menu.
2. From the project folder run:

   ```
   godot --headless -s tools/make_scenario.gd -- <slot> <scenario_id> "<title>" "<description>"
   ```

3. Translate the new pt_BR lines in `localization/core.csv` and commit
   `data/scenarios/<scenario_id>.json` and `.tres`. Details: `docs/scenarios.md`.

## What to try

1. New game, open the cheat panel, add funds, save to a slot named `test_a`.
2. Main menu → Continue: the funds are as you left them.
3. Scenarios → Fresh base: it starts paused.
4. Pause → Quit: it asks first.

## What to report

Anything that is hard to reach with the keyboard or gamepad, text that does not fit in pt_BR,
a save that will not load, and a cheat that does something other than its label says.
